# RescueHive — Phase 1: Command Center Dashboard UI

Continue development of the existing RescueHive project.

Phase 0 has already created the project foundation.

Now build the **frontend Command Center Dashboard**.

---

# IMPORTANT

This is a FRONTEND-ONLY phase.

Use mock/static data.

DO NOT connect to:

* Webots
* FastAPI APIs
* PostgreSQL
* YOLO
* SAM 2
* MiDaS
* real robot hardware

The purpose is to complete and polish the dashboard UI before connecting real systems.

All mock information must be clearly treated as simulation/demo data.

---

# UI GOAL

Create a professional disaster-response command center dashboard.

The dashboard should feel like a real emergency robotics control system.

Use:

* React
* Tailwind CSS
* shadcn/ui
* Lucide icons
* React Router

Design should be:

* dark command-center style
* professional
* clean
* information-dense but readable
* responsive
* suitable for desktop/laptop
* not overly colorful
* strong visual hierarchy

---

# APPLICATION PAGES

Create these routes:

/login

/dashboard

/robots

/detections

/missions

/reports

/settings

For now, navigation can work without real authentication.

# COMMAND CENTER

Create a dashboard containing:

## 1. Mission Summary

Cards:

* Mission status
* Mission duration
* Robots active
* Area explored
* Victims detected
* Hazards detected

---

## 2. LIVE MAP

Create a large map area.

For this phase, use mock data.

Display:

* 3 simulated robots
* robot positions
* robot names
* exploration paths
* victim markers
* hazard markers
* explored area

Use Leaflet if practical.

The map must clearly display:

**SIMULATION / MOCK DATA**

Do not pretend the data is coming from Webots.

---

## 3. ROBOT STATUS

Show cards/table for:

Robot Alpha
Robot Bravo
Robot Charlie

Each should show:

* status
* battery
* connection
* current task
* position
* explored area

Example statuses:

ACTIVE
EXPLORING
RETURNING
OFFLINE

---

## 4. DETECTION PANEL

Show recent detections.

Example:

Victim detected
Fire detected
Gas cylinder detected
Debris detected
Emergency exit detected

Each detection should contain:

* type
* confidence
* robot
* timestamp
* status

CONFIRMED
PENDING

---

## 5. ALERT PANEL

Create an emergency alert section.

Example:

HIGH — Fire detected by Robot Alpha

MEDIUM — Robot Bravo battery below threshold

Use appropriate icons and visual priority.

Show:

* exploration percentage
