# RescueHive — Phase 0: Project Foundation

You are working on a college project called:

**RescueHive — AI-Powered Multi-Robot Disaster Intelligence System**

Read and follow the project architecture described below carefully.

## IMPORTANT PROJECT BOUNDARY

This project has two major parts:

1. **RescueHive Platform** — MY responsibility

   * React frontend
   * FastAPI backend
   * PostgreSQL database
   * AI/CV pipeline
   * Mission management
   * Authentication
   * Dashboard
   * APIs
   * Integration with an external Webots simulator

2. **Webots Multi-Robot Simulator** — handled by another team member

   * DO NOT build the Webots simulation.
   * DO NOT create robot controllers.
   * DO NOT implement SLAM/navigation inside this project yet.
   * Assume the simulator will later expose APIs/WebSocket endpoints that RescueHive can connect to.

The external simulator will be integrated in a later phase.

---

# PHASE 0 OBJECTIVE

Create only the clean, scalable project foundation.

Do NOT implement the full dashboard, AI, simulator integration, or business logic yet.

The purpose of this phase is to establish a professional project structure that later phases can build upon.

# FRONTEND SETUP

Initialize the React + Vite application.

Configure:

* Tailwind CSS
* shadcn/ui
* React Router
* Lucide React

Create a basic application shell.

Do not build the complete dashboard yet.

The application should start successfully with:

npm run dev

---

# BACKEND SETUP

Create a FastAPI application.

The backend must start successfully using:

uvicorn app.main:app --reload

Create:

GET /api/v1/health

Response:

{
"status": "ok",
"service": "rescuehive-backend"
}

Configure CORS for local frontend development.

Create configuration handling through environment variables.

Example:

DATABASE_URL=
JWT_SECRET=
FRONTEND_URL=
ENVIRONMENT=development

Do not implement authentication yet.

Do not implement database models yet.
