# AI Vision Pipeline — Overview

This directory houses the future AI/CV pipeline modules for disaster intelligence analysis.

## Subdirectories
- `detection/`: Future object detection models (e.g., YOLO for victim, fire, rubble detection)
- `segmentation/`: Future image segmentation models (e.g., SAM 2 for hazard zoning)
- `depth/`: Future monocular depth estimation models (e.g., MiDaS for terrain traversability)
- `models/`: Checkpoints and model weight artifacts registry

*Phase 0 status: Structure initialized. Models will be implemented in later phases.*
